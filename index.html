Two-Stage Installation Protocol Zero Hardware Disassembly

Field-tested deployment procedure for MediaTek Filogic 830 / MT7986A dual-slot SPI-NAND routers (including the Arcadyan / Jio JIDU6101):

  • Flash Backup: Preserve unique RF calibration (Factory, MFG).
  • Stage 1 (Ramdisk): Staging initramfs kernel into secondary flash slot via UBI.
  • Stage 2 (Sysupgrade): Final persistent flash write purely in DDR3 RAM.

Disaster Recovery & Unbricking 3.3V TTL Strictly Mandated

Engineering methodology for diagnosing, recovering, and unbricking OpenWrt devices across 5 escalation tiers:

  • Tier 1 Failsafe: Rapid 10 Hz button interrupt and telnet failsafe mount.
  • Tier 2 Bootloader TFTP: Automated image restoration via bootloader pull.
  • Tier 3 Serial UART: 3.3V TTL console recovery — NEVER CONNECT VCC.

Evidentiary Verification Hierarchy

Every entry in this database is governed by our strict research hierarchy. No speculative specifications or AI-hallucinated compatibility claims are accepted.

1. Upstream OpenWrt Tree

Mainline Git commits, device tree sources (.dts), image Makefiles, and official release manifests.

2. Table of Hardware (ToH)

Verified Table of Hardware records and official Firmware Selector REST API data.

3. Hardware Teardowns & FCC

High-resolution PCB teardown photography, FCC test filings, component markings, and UART captures.
