Hardware Selection Principles

Unlike generic consumer review websites that evaluate routers solely by retail Wi-Fi speed stickers, the OpenWrt Hardware Knowledge Base analyzes the underlying silicon architecture, driver upstream status, and hardware maintainability:

1. Upstream Drivers

We prioritize chipsets supported by open-source Linux kernel drivers (mt76, ath9k, ath10k, ath11k, ath12k) over proprietary closed blobs.

2. Storage Headroom

Minimum 128 MB flash is required for modern OpenWrt 23.05/24.x kernels, LuCI web interface, WireGuard VPN, and security updates.

3. Unbrickability

Every recommended router features documented TFTP automated recovery or accessible 3.3V TTL serial UART pads.
