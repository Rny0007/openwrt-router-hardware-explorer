Installation Prerequisites
  • Stock firmware backup (bootloader, calibration/factory partition, MAC addresses).
  • 3.3V TTL USB-to-UART serial interface or verified OEM web interface firmware upgrade unlocked.
  • Wired gigabit Ethernet connection with static IPv4 assignment on host.
Upgrade & Downgrade Restrictions
  • Never preserve settings when upgrading across major OpenWrt branches (e.g. 21.02 swconfig to 22.03+ DSA switch).
  • Verify partition table layout matches U-Boot environment variables before sysupgrading NAND devices.
  • Reverting to OEM firmware requires restoring stock mtd partitions using U-Boot serial console or TFTP push.
  • Do not flash stock OEM firmware directly via OpenWrt LuCI sysupgrade; OEM headers will fail validation.
Known Firmware Regressions & Quirks:
  • No active firmware regressions logged for verified stable releases.

Fixed in: OpenWrt 21.02.0 (hostapd 2021-05-20)

Fixed in: OpenWrt 22.03.0 (U-Boot 2021.07+)
 Use read-only SquashFS partitions and restrict physical access to USB storage ports during boot.

Fixed in: OpenWrt 22.03.3 / 23.05.0

Fixed in: OpenWrt 23.05.1
