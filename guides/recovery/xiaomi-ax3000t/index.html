Xiaomi Router AX3000T Disaster Recovery & Unbricking

Primary Recovery Protocol: U-Boot Recovery Webpage | UART Serial: Available @ 115200 baud

CRITICAL SAFETY MANDATE — NEVER CONNECT VCC (RED WIRE): When connecting a USB-to-TTL serial adapter to the Router AX3000T PCB, connect ONLY GND, TX, and RX. The router provides its own 3.3V/1.8V power rail when plugged into its AC adapter. Connecting the red VCC wire from your USB adapter will backfeed voltage into the power management IC and permanently destroy the SoC and flash chips! Ensure your USB adapter logic level is set to 3.3V TTL (never 5V, never RS-232 +/-12V).

1. Recovery Escalation Hierarchy

Always attempt recovery in order of increasing intervention. Do not disassemble the enclosure until software fail-safes are exhausted.

TierMethodWhen to UseHardware Required
Tier 1 OpenWrt Failsafe Mode Kernel boots, network config broken, forgotten root password Ethernet cable, computer set to DHCP or static 192.168.1.2
Tier 2 TFTP Automated Bootloader Push Bootloader intact, corrupted kernel / rootfs, boot loop Ethernet cable, TFTP server utility (e.g. dnsmasq / tftpd32)
Tier 3 3.3V TTL Serial UART Console Bootloader prompt accessible, TFTP fails, diagnose boot failure 3.3V USB-UART adapter (CP2102/FTDI), jumper wires, soldering iron (if pads unpopulated)
Tier 4 External SPI Flash Programmer Bootloader erased/corrupted (hard brick), no serial output CH341A programmer, SOIC-8 / SOIC-16 test clip, full mtd0 raw flash dump

2. Tier 1: OpenWrt Failsafe Mode

  1. Disconnect all cables from router except power and LAN Port 1 to your computer.
  2. Set computer network interface to static IP: 192.168.1.2, netmask: 255.255.255.0, gateway: 192.168.1.1.
  3. Power on the router. As soon as the status or power LED begins blinking, press the WPS / Reset button repeatedly.
  4. The status LED will begin blinking extremely rapidly (10 Hz), indicating Failsafe mode is active.
  5. Connect via Telnet: telnet 192.168.1.1. No password is required.
  6. Reset configuration to factory defaults: 
    mount_root
firstboot -y
sync && reboot

3. Tier 2: Bootloader TFTP Restoration

Router Recovery IP192.168.1.1
Host PC TFTP Server IP192.168.1.2
Subnet Mask255.255.255.0
Expected TFTP Filenamexiaomi-ax3000t.bin
  1. Download official OpenWrt factory firmware image from the repository.
  2. Rename image file to xiaomi-ax3000t.bin and place in TFTP server root directory.
  3. Configure host PC Ethernet to static IP 192.168.1.2.
  4. Power off router. Hold Reset button down and power on. Hold for 10-15 seconds until TFTP request is detected.
  5. Observe file transfer in TFTP server logs. Allow 3-5 minutes for flash write and reboot.

4. Tier 3: 3.3V TTL Serial UART Console

Adapter PinRouter HeaderMandatory Instruction
GND (Black)GND Pad / PinConnect securely to establish common ground reference.
RX (White)TX Pad / PinConnect adapter RX to router TX.
TX (Green)RX Pad / PinConnect adapter TX to router RX.
VCC (Red)DISCONNECTEDDO NOT CONNECT! Router powers itself from AC barrel jack.

Configure your terminal emulator (PuTTY, Minicom, Picocom, or Screen):

# Linux / macOS screen command
screen /dev/ttyUSB0 115200 8N1

# Picocom command
picocom -b 115200 -d 8 -p n -f n /dev/ttyUSB0

Power on router and observe U-Boot bootlog. Press Enter/Space to enter U-Boot shell:

# Check environment variables
printenv

# Boot kernel via TFTP
setenv ipaddr 192.168.1.1
setenv serverip 192.168.1.2
tftpboot 0x46000000 xiaomi-ax3000t.bin
bootm 0x46000000

5. Calibration & Partition Preservation

If you previously dumped your Factory, ART, or MFG partitions prior to bricking, you can restore them via serial console or OpenWrt shell: 
mtd write /tmp/mtd_Factory.bin Factory
mtd write /tmp/mtd_ART.bin art
Never flash another router's calibration partition! Each contains unique physical RF power calibration values and factory MAC addresses.
