TFTP & Serial UART Disaster Recovery Guide

Comprehensive procedures for restoring unbootable or misconfigured OpenWrt hardware.

1. TFTP Automated Network Recovery

When the router's bootloader is intact but the kernel or rootfs is corrupted, MediaTek U-Boot attempts to fetch an emergency image over TFTP upon powering on with the Reset button held down.

  • Set Host PC Static IP: 192.168.1.10 (Netmask 255.255.255.0)
  • Connect Cat6 cable to LAN Port 1
  • Run a TFTP server (e.g. tftpd64) serving openwrt-initramfs.bin
  • Hold physical Reset button for 10 seconds while powering on

2. 3.3V TTL Serial UART Console Wiring

ELECTRICAL VOLTAGE WARNING: Router serial headers operate at 3.3V TTL logic levels. Connecting standard RS-232 (+12V/-12V) or connecting the USB adapter's VCC pin can instantly fry the SoC GPIO controller.
PinFunctionWiring Instruction
GNDGroundConnect to USB-UART Adapter GND
TXTransmit (Router -> PC)Connect to USB-UART Adapter RX
RXReceive (PC -> Router)Connect to USB-UART Adapter TX
VCCPower (3.3V)LEAVE DISCONNECTED (NEVER CONNECT)

Baud Rate: 115200 | Data bits: 8 | Parity: None | Stop bits: 1 | Flow Control: None
