Ubiquiti UniFi AC Pro (UAP-AC-Pro) OpenWrt Installation Guide

Architecture: mips_24kc | Target: ath79/generic/generic | Profile: ubnt_unifi-ac-pro

MANDATORY FACTORY CALIBRATION BACKUP: Before installing OpenWrt, backup all factory partition data (including ART, Factory, and EEPROM partitions). These contain factory RF calibration parameters, Wi-Fi MAC addresses, and regulatory domain constraints unique to your unit.

2. Step-by-Step Installation Procedure

  1. Access Vendor Debug Shell: Connect via Telnet or SSH using vendor administrative or engineering credentials.
  2. Transfer OpenWrt Firmware: Transfer OpenWrt factory image to /tmp using SCP, TFTP, or curl: 
    cd /tmp
tftp -g -r openwrt-factory.bin 192.168.1.2
  3. Write to Flash Partition: Identify active kernel/rootfs partition and write firmware: 
    mtd -r write openwrt-factory.bin firmware
  4. Reboot into OpenWrt: Allow router to complete writing and automatically reboot. Access LuCI web interface at http://192.168.1.1.

3. First Boot & Initial Configuration

  1. Connect your computer to LAN Port 1 using a Cat6 Ethernet patch cable.
  2. Verify computer receives IP address in subnet 192.168.1.0/24 via DHCP (e.g. 192.168.1.150).
  3. Open terminal and verify ping to router gateway: ping 192.168.1.1.
  4. SSH into router: ssh root@192.168.1.1 (no password initially required).
  5. Set secure administrator password immediately: 
    passwd
  6. Open web browser and navigate to http://192.168.1.1 to log into LuCI Web Interface.

4. Post-Installation Verification & Troubleshooting

Symptom / CheckProbable CauseResolution Action
No DHCP lease on computer Computer connected to WAN port instead of LAN port Connect cable to LAN Port 1; assign static IP 192.168.1.50 on host PC.
Status LED pulsing continuously Router booting into failsafe or storage expanding Wait up to 3 minutes; if still pulsing, power cycle while holding reset for 2 sec to trigger failsafe.
LuCI web interface not loading Minimal image installed without uhttpd/luci packages Connect WAN port to upstream internet, SSH in, and run: opkg update && opkg install luci.
