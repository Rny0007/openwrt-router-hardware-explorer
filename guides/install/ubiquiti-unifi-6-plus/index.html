Ubiquiti UniFi 6+ Installation Guide

Method: Automated Root SSH Exploit | Target Architecture: mediatek/filogic

2. Step-by-Step Installation Procedure

TWO-STAGE EXPLOIT UNLOCK & CALIBRATION BACKUP: This device runs OEM vendor firmware with locked SSH. Installation requires obtaining temporary root access via web command injection or vendor debug utility, backing up RF calibration partitions, and flashing an initramfs staging kernel.
  1. Obtain Root Shell: Follow the community-verified root exploit procedure (e.g. OpenWrt Inception, vendor web GUI token exploit, or telnet unlock script) to establish an SSH root session on the stock firmware.
  2. Mandatory RF Calibration Backup: Identify device partition layout and dump factory wireless calibration before touching flash: 
    cat /proc/mtd
# Identify Factory, ART, or Bdata partition numbers
dd if=/dev/mtdX of=/tmp/Factory_backup.bin
# Verify file size and transfer to PC via SCP!
  3. Flash OpenWrt Factory Staging Kernel: Transfer openwrt-mediatek/filogic-initramfs-factory.ubi (or factory.bin) to /tmp and write to the designated firmware/kernel partition.
  4. Reboot into OpenWrt RAM: Reboot router and wait for status LED to stabilize. Access OpenWrt in RAM at http://192.168.1.1.
  5. Final Sysupgrade: Perform permanent sysupgrade to commit OpenWrt to flash: 
    sysupgrade -n /tmp/openwrt-sysupgrade.bin

3. Post-Installation Initial Configuration

After successfully flashing OpenWrt, complete these essential configuration steps:

  1. Connect your PC to any LAN port. Verify IP assignment via DHCP in subnet 192.168.1.0/24.
  2. Open browser to http://192.168.1.1. Stock OpenWrt boots with username root and no password set.
  3. Immediately assign a strong root administrative password under System → Administration.
  4. Connect WAN port to upstream ISP or modem. Navigate to Network → Interfaces → WAN to confirm DHCP or PPPoE connection.
  5. Enable wireless radios under Network → Wireless. (Wi-Fi radios boot disabled by default for regulatory compliance).
