Two-Stage OpenWrt Installation Guide

Verified protocol for MediaTek MT7986A / Filogic 830 dual-slot SPI-NAND routers.

CRITICAL SAFETY PREREQUISITE: Never flash any router without dumping and verifying your factory calibration partitions (Factory, MFG). These contain unique MAC addresses and radio RF calibration parameters that cannot be recovered from public images.

1. Mandatory Pre-Installation Flash Backup

Log into your router via SSH and transfer full binary dumps to your host computer:

# [Router Shell]
cat /proc/mtd
dd if=/dev/mtd0 of=/tmp/mtd0_fullchip.bin bs=128k
dd if=/dev/mtd3 of=/tmp/mtd3_Factory.bin
dd if=/dev/mtd7 of=/tmp/mtd7_MFG.bin

# [Host PC Terminal]
scp root@192.168.1.1:/tmp/mtd*_*.bin ./backup/

2. Stage 1: Ramdisk Staging in Secondary Slot

Write the initial ramdisk kernel to mtd6 and set temporary U-Boot parameters to bypass OEM signature checks without touching permanent bootloader code:

ubiformat /dev/mtd6 -y -f /tmp/openwrt-factory.ubi
fw_setenv bootcmd "ubi detach; ubi part ubi2; ubi read 46000000 kernel; fdt addr \$(fdtcontroladdr); fdt rm /signature; bootm 0x46000000"
fw_setenv dual_boot.slot_0_invalid 1
fw_setenv dual_boot.slot_1_invalid 1
sync && reboot

3. Stage 2: Permanent Sysupgrade Flashing

The router reboots into OpenWrt operating purely in DDR3 RAM at 192.168.1.1. Upload the final official OpenWrt 25.12.6 sysupgrade image and flash permanently:

sysupgrade -n /tmp/openwrt-sysupgrade.bin
